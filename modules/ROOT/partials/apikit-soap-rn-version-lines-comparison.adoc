=== APIkit for SOAP Versions
[%header,cols="15a,20a,25a,40a"]
|===
| Line | Version | Minimum Platform | Use Cases

| Current major
| 3.0.0
| JDK 17 only; Mule runtime 4.9.11 and later
| You start a new SOAP API on current Mule and Java 17. This line supports Spring 7 and does not bundle Spring. Add Spring 7 as a shared library to apply `cxf.xml`.

| Supported major
| 2.x (2.0.0 and later)
| JDK 17 only; Mule runtime 4.9.11 and later
| You keep CXF customizations in `cxf.xml` without supplying Spring. This line still bundles Spring.

| Legacy compatibility
| 1.7.0
| JDK 8, 11, or 17; Mule runtime 4.1.x and later
| You keep existing deployments on earlier Mule or Java stacks.

| Deprecated
| 1.6.5 – 1.6.10
| Deprecated releases.
| Migrate to 1.7.0, 2.x, or 3.0.0 using the xref:apikit::apikit-4-for-soap.adoc#choose-the-apikit-for-soap-module-version[version selection guide].
|===
