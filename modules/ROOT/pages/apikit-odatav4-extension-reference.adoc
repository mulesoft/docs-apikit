= APIkit for OData v4 Module Reference
ifndef::env-site,env-github[]
include::_attributes.adoc[]
endif::[]

Configure APIkit for OData v4 in Mule with the Maven dependency, `apikit-odata` namespace, and schema location listed in this reference. Later sections document `Config`, operations, and listeners you use when you scaffold or extend OData v4 APIs.

== Dependency Information

----
<dependency>
  <groupId>org.mule.modules</groupId>
  <artifactId>mule-odata-module</artifactId>
  <version>LATEST_VERSION</version> //<!--1-->
  <classifier>mule-plugin</classifier>
</dependency>
----
[calloutlist]
.. Check https://docs.mulesoft.com/release-notes/apikit/apikit-release-notes[APIkit release notes] to get the *LATEST_VERSION*.

xmlns:apikit-odata="http://www.mulesoft.org/schema/mule/apikit-odata"
