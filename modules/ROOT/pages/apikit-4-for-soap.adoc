APIkit for SOAP is a framework for simplifying the development and integration of SOAP-based APIs. SOAP (Simple Object Access Protocol) is a messaging protocol for exchanging structured information between web services. APIkit for SOAP manages SOAP message formats and headers to ensure seamless integration with SOAP infrastructure. With APIkit for SOAP, you can create robust and reliable SOAP-based APIs, accelerating your development workflow and delivering enhanced integration capabilities.

== APIkit for SOAP Features

* Streamlines SOAP API development, ensuring seamless integration with your existing SOAP infrastructure.
* Simplifies the handling of SOAP message formats and headers, so you can focus on the core logic of your APIs. 
* Automates the binding to WSDL (Web Services Description Language), reducing manual configuration efforts and ensuring accuracy.
* Supports data transformations.
* Defines and exposes SOAP APIs with ease by emphasizing SOAP/WSDL contracts. 

=== Supported Characters

APIkit for SOAP supports a variety of characters, including alphanumeric, special, Unicode, and C0 control characters. To ensure proper encoding and XML compliance, certain characters must be escaped. APIkit for SOAP supports these characters:

[cols="1,2", options="header"]
|===
| Character Type | Description

| Alphanumeric Characters
| A-Z, a-z, 0-9

| Special Characters
| Common special characters such as !, @, #, $, %, ^, &, *, (, ), -, _, =, +, [, ], {, }, \|, \, ;, :, ', ", ,, ., <, >, /, ?, ~, and \. 

| C0 Control Characters
| Control characters such as `NULL` (`\u0000`), `START OF HEADING` (`\u0001`), `START OF TEXT` (`\u0002`), and others. Verify that they are properly encoded to ensure XML compliance.
| Escaped Characters
| Special XML characters like `<`, `>`, `&`, `"`, and `'` must be escaped using their respective entity references: `&lt;`, `&gt;`, `&amp;`, `&quot;`, and `&apos;`
|===
