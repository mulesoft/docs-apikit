APIkit for SOAP simplifies building and integrating SOAP-based web services by handling message formats, headers, and WSDL binding against your existing SOAP endpoints. SOAP (Simple Object Access Protocol) exchanges structured payloads between services; APIkit for SOAP keeps those payloads aligned with your contracts. Ship reliable APIs faster with automated configuration, data transformation, XML 1.0 defaults, and optional XML 1.1 C0 characters through the xref:apikit-4-xml-reference.adoc#apikit-for-soap-system-properties[system property].

[#choose-the-apikit-for-soap-module-version]
== Choose the APIkit for SOAP Module Version

APIkit for SOAP now has two versions so you can align the module with your Mule runtime and JDK. Choose the version that matches the platform you deploy today. For more information about installation, see xref:apikit-4-soap-prerequisites-task.adoc[].

== APIkit for SOAP Features

* Streamlines SOAP API development, ensuring seamless integration with your existing SOAP infrastructure.
* Simplifies the handling of SOAP message formats and headers, so you can focus on the core logic of your APIs. 
* Automates the binding to WSDL (Web Services Description Language), reducing manual configuration efforts and ensuring accuracy.
* Supports data transformations.
* Defines and exposes SOAP APIs with ease by emphasizing SOAP/WSDL contracts. 
* Supports XML 1.0 characters by default. Supports XML 1.1 C0 characters through the xref:apikit-4-xml-reference.adoc#apikit-for-soap-system-properties[system property].
