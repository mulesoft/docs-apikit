= Implementing a SOAP Interface
ifndef::env-site,env-github[]
include::_attributes.adoc[]
endif::[]

Use Anypoint Studio and APIkit for SOAP to build a Mule integration that calls a remote SOAP service and exposes it as part of your API surface. The walkthrough uses link:{attachmentsdir}/tshirt2.wsdl[tshirt2.wsdl] so you map WSDL operations to flows and connect downstream systems behind the SOAP contract.

Confirm that xref:apikit-4-for-soap.adoc#choose-the-apikit-for-soap-module-version[APIkit for SOAP 1.7.0, 2.x, or 3.0.0] matches your Mule runtime, JDK, and CXF configuration before you scaffold your project.

Start by xref:apikit-4-soap-project-task.adoc[creating an APIkit for SOAP project].
