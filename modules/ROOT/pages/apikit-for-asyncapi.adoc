= APIkit for AsyncAPI
ifndef::env-site,env-github[]
include::_attributes.adoc[]
endif::[]

APIkit for AsyncAPI implements event-driven APIs from AsyncAPI specifications that use asynchronous messaging protocols. Add and configure module operations in Mule flows so you publish and consume messages through your chosen bindings. AsyncAPI models reliable, event-based integration among systems; the APIkit scaffolder produces a minimal Mule implementation you import from xref:exchange::index.adoc[Anypoint Exchange] and re-scaffold in xref:anypoint-code-builder::imp-asyncapi.adoc[Anypoint Code Builder] or xref:studio::import-api-specification-exchange.adoc#implement-asyncapi-specifications[Anypoint Studio]. With xref:apikit-asyncapi-module-reference.adoc#validation-of-messages[message validation] enabled, the module validates `listener` and `publish` payloads against your schemas.

[NOTE]
APIkit for AsyncAPI supports the https://www.asyncapi.com/blog/release-notes-2.6.0[AsyncAPI 2.6 spec].
