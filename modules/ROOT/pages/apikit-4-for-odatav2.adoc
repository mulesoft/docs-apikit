= APIkit for OData V2
ifndef::env-site,env-github[]
include::_attributes.adoc[]
endif::[]

APIkit for OData v2 uses standard HTTP to build RESTful APIs that follow the OData v2 specification and the Open Data Protocol (OData) for querying and updating data. The extension layers on APIkit for REST and RAML contracts so you combine OData v2 tooling with the same REST design workflow. It offers fewer capabilities than OData v4 and some newer stacks; choose OData v4 when you need the latest protocol features and query model.
