APIkit for SOAP maps routing failures and SOAP fault conditions to typed errors you handle in Mule. The table in this reference lists each APIKIT-SOAP error type and what it indicates. The scaffolder does not generate default error-handling logic; add `on-error` strategies in your flows as needed.

== APIkit for SOAP Error Types

APIkit for SOAP defines two error types:

[%header]
|===
|Error Type |Description

|APIKIT-SOAP:ROUTER
|Routing exception

|APIKIT-SOAP:FAULT
|Fault exception
|===

== APIkit for SOAP Error Handling

APIkit for SOAP scaffolder generates no error-handling code.
