= Supported Bindings in APIkit for AsyncAPI 
ifndef::env-site,env-github[]
include::_attributes.adoc[]
endif::[]

APIkit for AsyncAPI supports various bindings to facilitate message-driven architectures.

[%header%autowidthspread]
|===

| Connector | Publish | Message Listener | Description | Reference

| AnypointMQ | `destination` | `destination` | The description is optional. It defaults to the channel name. The `destination` (queue or exchange) name for this channel. The description must be specified if the channel name differs from the actual `destination` name. For example, if the channel name is not a valid `destination` name in Anypoint MQ. | See https://github.com/asyncapi/bindings/blob/b1e7736071ccddc6c3d652bb2071cad4549f8a08/anypointmq/README.md[Anypoint MQ Bindings].

.3+| Solace 
| deliveryMode | deliveryMode | 'direct' or 'persistent'. This determines the quality of service for publishing messages. Default is 'persistent'. | https://github.com/asyncapi/bindings/blob/master/solace/README.md

| destinationType | destinationType | Currently only ‘queue’ is supported in asynckit EDA. | https://github.com/asyncapi/bindings/blob/master/solace/README.

| N/A | topicSubscriptions | A list of topics that the queue subscribes to, only applicable when destinationType is 'queue'. If none is given, the queue subscribes to the topic as represented by the channel name. | https://github.com/asyncapi/bindings/blob/master/solace/README.md

|===

[NOTE]
Kafka and Solace Pub/Sub connectors don't support bindings.
