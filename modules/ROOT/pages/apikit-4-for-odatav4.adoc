= APIkit for OData V4
ifndef::env-site,env-github[]
include::_attributes.adoc[]
endif::[]

APIkit for OData v4 delivers RESTful APIs that comply with the OData v4 specification. It uses standard HTTP for querying and updating data through the Open Data Protocol (OData). Generate Mule flows that handle OData requests so you can modernize legacy APIs, orchestrate data into Salesforce, or expose bidirectional OData surfaces for databases such as Oracle, DB2, or Azure DB. Unlike the RAML-based APIkit for OData v2 extension, APIkit for OData v4 uses the OData Entity Data Model (EDM) to describe resources and structures for HTTP-based data services.
